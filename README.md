# Ludo-3

Ludo Rush Flutter source (**characters stripped** for fast upload).

## 1. Upload source zip
Upload `Ludo_Rush_Source.zip` (~2.7 MB, no character PNGs) to the **repo root**.

## 2. Build
Push / workflow_dispatch runs **Build Android APK**:
- arm64-v8a only
- Gradle 8.14.3 · Kotlin 2.2.20 · AGP 8.11.1

## 3. Download APK
**Releases** → `LudoRush.apk` (or Actions → artifact `ludo-rush-apk`)

## 4. Characters later (MT Manager)
```
assets/flutter_assets/assets/characters/
```
